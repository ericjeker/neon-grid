# Neon Inventory

Neon Inventory is a "Backend" module. It handles data: What do I have? How much does it weigh? What is the icon? It 
shouldn't care about Skeletal Meshes, sockets, muzzle flashes, or reloading logic.

This module is designed to be flexible and extensible, allowing for easy integration with various game systems and 
components. It provides a standardized way to manage and track inventory items, ensuring consistency and reliability 
across different parts of the game.
